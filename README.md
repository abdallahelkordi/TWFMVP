# TWF MVP

TWF MVP is the first prototype of **The Women’s Football** platform.

## Vision
TWF aims to become the trusted digital home of women’s football by combining:

- player profiles
- club profiles
- league visibility
- football storytelling
- valuation logic
- commercial potential

## Current MVP Structure

- `index.html` → homepage
- `players.html` → players listing
- `player.html` → player profile
- `clubs.html` → clubs listing
- `club.html` → club profile
- `league.html` → leagues page
- `style.css` → global styling
- `script.js` → basic scripts

## Current Goal
This MVP is being built as a prototype to:

- shape the product vision
- define the user experience
- create a clear structure
- prepare for future full-stack development

## Future Roadmap

### Phase 1
- clean MVP prototype
- strong branding
- better user flow

- richer profiles

### Phase 2
- database integration
- real player and club data

### Phase 3
- valuation engine
- club and player comparison

## Brand Direction
